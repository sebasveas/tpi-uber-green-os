## Descripción del Proyecto
Este repositorio contiene el desarrollo del **Trabajo Práctico Integrador (TPI)** enfocado en el diseño del módulo **Uber Green OS** para la empresa *Uber Technologies Inc.*

### 🛠️ Entregas del Proyecto:
- **Entrega 1:** Enfoque Sistémico y Caso de Estudio (TGS).
- **Entrega 2:** Diagnóstico Estratégico (FODA) y Planificación Temporal (Gantt).
- **Entrega 3:** Estructura Formal (Organigrama) y Diccionario de Datos.
- **Entrega 4:** Modelado de Procesos (BPMN 2.0), Git Flow, Kanban y Control Organizacional.
